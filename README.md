# Istanbul-Housing-Rental-Dataset
📊 Technical Report: End-to-End Analysis &amp; Machine Learning Modeling on Istanbul Housing &amp; Rental Dataset
EXECUTIVE SUMMARY
This project delivers a comprehensive end-to-end data science study on the Istanbul housing and short-term rental market. The workflow encompasses exploratory data analysis (EDA), data cleaning, statistical modeling, Machine Learning and Deep Learning predictions, as well as the implementation of a full-stack Desktop Database Management System using Python

1. ENVIRONMENT SETUP & LIBRARY INITIALIZATIONTo execute the pipeline, the environment was configured with specialized Python packages spanning three core domains:Data Manipulation & Analysis: Pandas and NumPy were utilized for dataset structuring, array transformations, and statistical summaries.Data Visualization: Matplotlib and Seaborn were employed to conduct univariate, bivariate, and correlation analysis.Machine Learning & Deep Learning: Scikit-Learn was integrated for feature scaling, train-test splitting, and regression modeling, while TensorFlow / Keras was leveraged for deep neural network architectures.Database & GUI Application: Tkinter and SQLite3 were used to construct an interactive graphical user interface connected to a relational database backend.   2. DATA PREPROCESSING & EXPLORATORY DATA ANALYSIS (EDA)During the data exploration phase, several critical structural insights and data quality anomalies were identified and addressed:A. Deduplication & Data IntegrityDuplicate Detection: Initial audits revealed a significant proportion of duplicate records resulting from repeated property listings.Data Cleaning: Redundant entries were purged to prevent data leakage and avoid biasing downstream modeling.B. Missing Value ImputationPattern Analysis: Missing fields across feature columns were examined.Imputation Strategy: Frequently occurring values (mode) and central tendencies (median) were applied to replace missing entries without disrupting overall distributional characteristics.

2. C. Feature Relationship & Correlation AnalysisMultivariate Exploration: Relationships between variables such as Neighbourhood, Room Type, Number of Reviews, and Availability_365 were examined against pricing metrics.Pricing Dynamics: While Price exhibited variability across specific clusters, it did not act as a dominant linear driver across the dataset.Correlation Heatmap Insights: The correlation matrix demonstrated a weak linear relationship between Price and most available numerical attributes, indicating early on that linear predictive models would face complexity challenges.3. MACHINE LEARNING & DEEP LEARNING MODELINGFollowing preprocessing, predictive pipelines were established to model property pricing trends:Model Implementations: Multiple regression algorithms were evaluated alongside a Deep Neural Network (DNN) built with Keras.Performance Evaluation: Predictive metrics (e.g., $R^2$ score, Mean Squared Error) yielded lower-than-expected accuracy rates.Root Cause Analysis:Low Feature Correlation: As established during EDA, the available features lacked strong linear dependencies with target prices.Unobserved Variance: Property pricing in real estate is heavily influenced by unrecorded qualitative variables (e.g., interior condition, proximity to landmark amenities, seasonal inflation) not present in the current dataset.4. DATABASE & GUI APPLICATION IMPLEMENTATIONTo bridge analytical insights with operational utility, a standalone desktop database application was built using Python Tkinter & SQLite:   User Interface: Engineered with a responsive fixed layout (1500x1000 resolution) supporting full visibility for all 12 dataset attributes.   CRUD Capabilities: Supports real-time Create (Add), Read (Display), Update (Update), and Delete (Delete) operations linked to a local SQLite database.   Usability Enhancements: Features interactive keyboard navigation via the Enter key, structured field-focusing, and integrated horizontal/vertical scrollbars for seamless dataset inspection.   5. CONCLUSION & RECOMMENDATIONSFeature Engineering & Data Acquisition: Incorporating additional domain-specific attributes (e.g., exact square footage, distance to public transit, property age) is strongly recommended to enhance predictive accuracy.Advanced Ensembling: Future iterations should evaluate non-linear tree-based ensemble models, such as XGBoost or CatBoost, to capture non-linear feature interactions.Application Integration: Integrate the finalized prediction pipeline into the Tkinter GUI to enable real-time price estimations upon entering new property details.
